# Decision Log — 2026-07-17

## Vite + React + TypeScript

Chose Vite 8 as the build tool with React 19 and TypeScript 6. Vite provides fast HMR, native ESM, and is the official React recommendation. TypeScript catches type mismatches between frontend and backend API payloads.

## Vite Dev Proxy for API

Configured `vite.config.ts` to proxy `/api` requests to `http://localhost:8080` (Go backend). This avoids CORS configuration during development and matches the production setup where both frontend and backend sit behind the same origin.

## Cookie-Based Session Authentication

The backend uses `session_key` cookies (HttpOnly, Secure, SameSite=Lax) with rotation. The frontend uses `credentials: 'include'` on all fetch calls so the browser sends the cookie automatically. No token storage is needed on the frontend side.

## Plain CSS (No CSS Framework)

Chose plain CSS over Tailwind, styled-components, or CSS Modules to keep the dependency footprint minimal at this early stage. CSS is organized per-component in `App.css` (single file) and global styles in `index.css`.

## Component Directory Structure

Pages live under `src/pages/` (one file per route), shared UI under `src/components/`. API calls are separated into `src/api/` with a thin `client.ts` wrapper. This follows the project's existing backend layering pattern (api / domain / database).
