# ChatRoomDetailPage — 訊息列表與發送功能

## 變更內容

在 `ChatRoomDetailPage` 實作即時通訊 UI，包含：

1. **Types** (`src/types/index.ts`)
   - 新增 `ChatMessage`、`MessageListResponse`、`MessageResponse` 介面

2. **API** (`src/api/chat.ts`)
   - 新增 `listMessages(roomId, beforeId?, limit?)` — GET 前端分頁查詢
   - 新增 `sendMessage(roomId, content, image?, file?)` — POST multipart/form-data

3. **頁面** (`src/pages/ChatRoomDetailPage.tsx`)
   - 掛載時呼叫 `listMessages` 取得訊息（API 回傳最新在前，頁面反轉為最舊在前）
   - 訊息氣泡：自己（右側藍底白字）、他人（左側灰底黑字）
   - 支援文字、圖片、檔案顯示與下載
   - 底部固定輸入區：textarea（Enter 送出）、圖片選取、檔案選取
   - 送出後 append 回傳訊息至 state，不清空全部

4. **CSS** (`src/App.css`)
   - `.chat-room-detail-page` 改為 flex column + `calc(100vh - 128px)` 撐滿視窗
   - 新增 `.chat-messages-container`、`.chat-message-*`、`.chat-bubble`、`.chat-input-area` 等樣式

5. **邀請成員頁面** (`src/pages/AddRoomMembersPage.tsx`、`src/api/members.ts`、`src/api/chat.ts`)
   - 新增 `MembersListResponse` type
   - 新增 `listMembers()` 查詢全部會員
   - 新增 `addRoomMembers()` 邀請成員進聊天室
   - 獨立頁面 `/chat/rooms/:roomId/add-members`，checkbox 選取 + 搜尋過濾
   - ChatRoomDetailPage header 加入「＋ 邀請成員」按鈕

## 原因

讓使用者在聊天室內能即時收發文字、圖片、檔案訊息，補齊私訊功能的最後一塊拼圖。
後續加入邀請成員功能，讓聊天室可以多人參與。
