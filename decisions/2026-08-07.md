# Playwright full-stack E2E suite (frontend)

## What
Add a Playwright full-stack E2E suite to the frontend repo: real React frontend (`:5173`) → real Go backend (`:8090`) → real Postgres (`productdb_e2e`). Implementation of the existing `plans/e2e-test.md`.

## Why
Everything in the plan has now been implemented and verified: config, backend launcher, DB teardown, specs, package scripts, gitignore, and GitHub Actions workflow. The suite is the single source of truth and is reusable from the backend repo's CI via `E2E_BACKEND_DIR`.

## Changes
- `playwright.config.ts`: testDir `e2e`, `webServer` array (backend via `scripts/start-backend.sh` + `npm run dev`), CI vs local options, chromium project.
- `scripts/start-backend.sh`: builds/runs the backend from `E2E_BACKEND_DIR` (default `../backend`), creates `productdb_e2e` if missing, keeps the process alive, cleans up on EXIT.
- `e2e/helpers.ts`: `registerAndLogin`, `login`, `unique`.
- `e2e/global-setup.ts`: creates the e2e DB and truncates application tables (RESTART IDENTITY CASCADE) along with SKIP list only exist in schema.
- `e2e/global-teardown.ts`: removes temp MEDIA_ROOT.
- Specs: `auth.spec.ts`, `product.spec.ts`, `inventory.spec.ts`, `announcement.spec.ts`, `chat.spec.ts`, `calendar.spec.ts`.
- `package.json`: `e2e`, `e2e:ui`, `e2e:report` scripts; added `@types/pg`.
- `.gitignore`: `test-results/`, `playwright-report/`, `blob-report/`.
- `.github/workflows/e2e.yml`: postgres service + checkouts (frontend + backend) + `npx playwright test`.

## Verification
`npx tsc -b` passes; `npx playwright test --list` discovers 9 specs across 6 files. Full local browser run (`npm run e2e`) against a real backend + `productdb_e2e` passes: 9/9 green. Temp `MEDIA_ROOT` and the e2e backend (port 8090) are cleaned up after the run.
