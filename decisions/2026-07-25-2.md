# Replace stub calendar events with real backend API calls

## What
Replaced the stub announcement and chat room data in `useCalendarEvents` hook with real API calls to the newly added backend endpoints:
- `GET /api/announcements?year=&month=` 
- `GET /api/chat/rooms?year=&month=`

## Why
Backend now supports month-filtered queries for announcements and chat rooms, so the frontend stub data is no longer needed.

## Changes
- `src/api/announcements.ts` — modified `listAnnouncements` to accept optional `year`/`month` params
- `src/api/chat.ts` — modified `listChatRooms` to accept optional `year`/`month` params
- `src/hooks/useCalendar.ts` — replaced `stubAnnouncements`/`stubChatTopics` with real API calls in `useCalendarEvents`
