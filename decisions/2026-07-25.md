# 多日曆事件標籤視覺連接

## 變更
讓日曆頁面中相同事件跨越多天時的標籤條，在視覺上連接在一起，而不是被日期格子邊框切斷。

## 修改檔案
- `src/pages/CalendarPage.tsx`
- `src/App.css`

## 實作方式
1. **包裝 Grid**：將原本的 calendar grid 用一個外層 div 包住，外層負責 `border-radius` 和 `overflow: hidden`，內層 grid 不再有 `overflow: hidden`，讓 connector 可以跨格延伸。

2. **CSS pseudo-element connectors**：
   - 在 `CalendarPage.tsx` 的 event bar 上加上 `data-has-next` 和 `data-has-prev` 屬性。
   - 在 `App.css` 中用 `::after`（向右連接）和 `::before`（向左連接）產生 13px 寬的 connector，顏色與 event bar 背景一致（使用 CSS custom property `--connector-bg`）。
   - connector 填滿 cell padding（6px + 6px）和 cell border（1px）之間的間距。

3. **Border 調整**：
   - 只有多日事件的第一天保留左側 3px 的 colored border，中間和最後一天的 bar 不顯示 border，讓 connector 無縫銜接。
   - 對應調整 padding 使文字起始位置一致。

4. **Overflow 調整**：
   - 有 `hasPrev` 或 `hasNext` 的 bar 設 `overflow: visible`（讓 pseudo-element 延伸出去），其他 bar 維持 `overflow: hidden`（保留 ellipsis 文字截斷）。

## 效果
多日事件（例如 7/1–7/5 的「產品發布會議」）的標籤條原本被日期格子的 padding 和 border 切斷成獨立區塊，現在會用同色的 connector 條跨格連接，視覺上像是一條連續的 bar。
