# Commit package-lock.json; enable npm ci + caching in CI

## What
Stopped ignoring `package-lock.json` and committed it. Updated all three frontend GitHub Actions workflows (`ci.yml`, `deploy.yml`, `e2e.yml`) to install dependencies with `npm ci` (instead of `npm install`) and enabled setup-node's `cache: npm`.

## Why
`actions/setup-node` with `cache: npm` requires the lockfile in the repo; because `package-lock.json` was gitignored, the E2E job failed with "Dependencies lock file is not found". Committing the lockfile enables reproducible installs (`npm ci`) and fast npm caching across `ci`/`deploy`/`e2e`.

## Changes
- Modified `.gitignore`: removed `package-lock.json`, which is now committed.
- Committed `package-lock.json`.
- Modified `.github/workflows/ci.yml`, `deploy.yml`, `e2e.yml`: `npm install` → `npm ci`, and `cache: npm` on `actions/setup-node@v4`.
