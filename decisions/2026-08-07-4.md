# Restyle registration codes page to match inventory management (2026-08-07)

## What
Restyled the admin `註冊代碼管理` page (`src/pages/RegistrationCodesPage.tsx`) so its layout and visual language mirror the `庫存管理` list page (`src/pages/InventoryListPage.tsx`), while preserving all existing functionality (list, inline create, delete, loading/error/empty states, available/total counts).

## Why
The registration codes page previously had no dedicated CSS (the classes `registration-codes-page`, `code-table`, etc. were unstyled) and looked inconsistent with the rest of the app. The user requested that it look like the inventory management page.

## Changes
- `src/pages/RegistrationCodesPage.tsx`:
  - Added a `back-link ← 返回首頁` to `/home` above the title, matching inventory's header pattern.
  - Added a `search-bar` with a client-side filter on the code (matches InventoryListPage's search UI and behavior).
  - Swapped `code-table` for `data-table` and reuse the inventory table column styling (kept 6 columns: 代碼/狀態/建立者/使用者/建立時間/操作).
  - Status now renders as `status-badge` with `status-available` (green) / `status-used` (gray) pills.
  - Empty state distinguishes `無符合條件的註冊代碼` (when searching) vs `目前尚無註冊代碼`.
- `src/App.css`: appended a `===== Registration Codes =====` section with `.registration-codes-page .data-table` styles mirroring inventory's, `.code-cell` monospace, `.status-available`/`.status-used` badge colors, and a `code-create-form` styled to match the inventory search input.
