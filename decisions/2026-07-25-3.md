# Calendar event routing by type

## What
Changed the calendar event bar click handler to route to different pages based on event type:
- `event` → `/calendar/${sourceId}`
- `announcement` → `/announcements/${sourceId}`
- `chat` → `/chat/rooms/${sourceId}`

## Why
Previously all event types routed to `/calendar/${id}`, which only works for native Event API events. Announcements and chat topics need to go to their respective detail pages.
