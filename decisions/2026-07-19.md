# Decision Log — 2026-07-19

## Announcement System Frontend

Added announcement (bulletin board) UI with list, detail, and create pages.

## Key Decisions

1. **AnnouncementListPage** (`/announcements`): long rectangular cards, newest first, centered layout. Public read access.

2. **AnnouncementDetailPage** (`/announcements/:id`): shows full content, image (if any), publisher name, and timestamps.

3. **AnnouncementCreatePage** (`/announcements/new`): separate form page, auth-gated. Uses multipart/form-data for image upload.

4. **API convention**: create/update use `multipart/form-data` (not JSON) because the backend handles image file uploads via `r.FormFile("image")`.

5. **Media proxy**: vite config proxies `/media/` to the Go backend for serving uploaded images.

6. **Dashboard**: added a "訊息" section header with a "佈告欄" card below the existing product cards.

7. **Navbar**: the previously disabled "訊息" nav item now links to `/announcements`.
