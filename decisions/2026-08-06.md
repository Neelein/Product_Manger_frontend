# Vercel CI/CD for frontend

## What
Added GitHub Actions workflows to build, lint, and deploy the frontend to Vercel. Added `vercel.json` to rewrite `/api` and `/media` requests to the backend at `http://neeleindev.com:8090`, and ignored the local `.vercel/` directory.

## Why
The frontend needs a hosting/CDN solution. Vercel hosts the static frontend while the Go backend stays on the existing self-hosted server. Because all frontend API calls use relative `/api` and `/media` paths, server-side rewrites keep the browser on the frontend origin — so the SameSite Lax session cookie keeps working and no CORS configuration is required.

## Branches
- `main` → production deploy (`vercel --prod`)
- `dev` → preview deploy

## Requirements
GitHub repo `Neelein/Product_Manger_frontend` secrets:
- `VERCEL_TOKEN`
- `VERCEL_ORG_ID`
- `VERCEL_PROJECT_ID`

## Changes

- New `.github/workflows/ci.yml` (lint + build on push to dev, PR to main)
